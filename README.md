# Country Data Fetcher

A beginner-friendly project that demonstrates how to work with APIs in JavaScript. This simple web application fetches and displays information about countries using the [REST Countries API](https://restcountries.com/).

## Features

*   **Search for a Country:** Enter a country's name to fetch and display its details.
*   **Get a Random Country:** Click a button to get information about a randomly selected country.
*   **Dark Mode:** A toggle switch to change between light and dark themes.

## How to Use

1.  Clone or download the repository.
2.  Open the `index.html` file in your web browser.
3.  To find a specific country, type the country's name into the input field and click "Search Country".
4.  To get a random country, click the "Get Random Country" button.
5.  Use the toggle switch in the top right to switch between light and dark modes.

## Technologies Used

*   HTML
*   CSS
*   JavaScript
*   [REST Countries API](https://restcountries.com/)
